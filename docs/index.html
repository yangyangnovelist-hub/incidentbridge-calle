01 / Controlled execution

One call. Five hard boundaries.

The workflow is inspectable before the phone rings. Ambiguity is not success, and a vendor’s words never replace local recovery checks.

01 / Validate

Non-secret incident

Bounded IDs, UTC timestamps, E.164 recipient and secret-marker rejection.

02 / Preview

Masked by default

No-call preview exposes the exact task, schema and decision boundary.

03 / Authorize

Exact recipient

Live mode requires explicit intent, an exact allowlist and server-side credential.

04 / Reserve

Duplicate-proof

A durable reservation is written before dispatch. Unknown outcomes lock retries.

05 / Route

Evidence, not closure

Ticketed acknowledgment or needs-human. Incident closed always remains false.

The agent may

Collect operational facts.

Disclose AI identity, ask for consent, obtain ticket ID, status, ETA, workaround and callback window, then return a bounded result.

The agent may not

Declare the incident recovered.

No credentials, payments, contract changes, hidden retries or recovery claims. Local health checks and the human incident commander own closure.
